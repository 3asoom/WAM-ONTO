# WAM-ONTO API Reference

## SPARQL Endpoints

### Query Interface
The ontology can be queried using standard SPARQL 1.1 syntax.

**Base URI:** `http://www.semanticweb.org/azabin/ontologies/2025/4/untitled-ontology-7/`

### Common Prefixes
```sparql
PREFIX wam: <http://www.semanticweb.org/azabin/ontologies/2025/4/untitled-ontology-7/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX owl: <http://www.w3.org/2002/07/owl#>
```

*Full API documentation is under development. See `examples/sample-queries.rq` for query examples.*
