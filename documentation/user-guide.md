# WAM-ONTO User Guide

## Overview
This guide provides comprehensive instructions for using the Water Asset Management Ontology.

*This documentation is currently under development. Please check back soon or contribute to help us complete it.*

## Quick Start
1. Download the ontology file: `ontology/wam-onto.owl`
2. Open in Protégé 5.5.0 or later
3. Enable HermiT reasoner for full functionality
